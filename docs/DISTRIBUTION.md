# 公开发行决策与维护方式

基线：上游 1.6.194，提交记录在 community-edition.json。未吸收生产工作目录的未提交变更。公开库使用新的 root commit，不继承旧仓库的历史。

本版落实的用户偏好：

1. 投研、学习、投资联赛的界面入口与脚本不发行；Main 不注册相关业务 IPC、不启动调度器，research 创建请求被拒绝。
2. 公司中转、作者本机生图集成和专用服务账号不在公开账号中心出现；初始状态不带任何作者登录。
3. 默认直连，Claude/OpenAI API 指向官方地址；用户可自行设置代理/网关。数据目录、应用标识和快捷方式独立。
4. 保留通用群聊、开发看板、原生会话、记忆和能力管理；首次首页提供 CLI 检测与账号入口。
5. 提供免 Node/Git 的便携安装、离线 ZIP 与 SHA256 校验、JSON 回执、源码安装/doctor、官方 CLI 安装辅助、agent 任务书、公司定制指南和云端打包验证。

不宣称无需账号、无需网络或所有功能零配置。AI 账号授权和模型权限来自用户；公司内部网关及自定义 CLI 要有自己的适配。使用成本由所选提供方决定。

维护时不要从个人仓库直接 `git push --mirror` 到这里。应在隔离分支更新基线、做公开文件清单检查、执行测试，再发布新版本。程序配置、token、真实会话、个人报告和本机安装日志不进入公开仓库或 Releases。

私有业务文件的排除由本次导出工具的 allowlist 与排除表完成，公开仓库保留最终代码和验证入口；不得将私人工作区全量复制到这里后依赖 .gitignore 补救。
